# САД №17 — демонстрационный сайт

САД №17 — вымышленный бренд и презентационная веб-концепция. Каталог и AI-изображения демонстрируют возможный образ коллекции; это не реальные товары, магазин или предложение к продаже. На сайте нет заказа, оплаты или доставки.

## Локальный просмотр

Проект статический и не требует сборки или установки зависимостей. Откройте PowerShell в корне этой папки и запустите:

```powershell
python -m http.server 8000
```

Затем откройте <http://localhost:8000/>. Для остановки сервера нажмите Ctrl+C.

## Публикация через GitHub Pages

В настройках репозитория откройте **Settings → Pages** и выберите публикацию из ветки `main`, папка `/ (root)`. Сохраните настройки и дождитесь, пока GitHub Pages опубликует содержимое. Файлы сайта находятся в корне проекта; сборочный шаг не нужен.

Адрес проекта: https://dementer11.github.io/sad17-atelier/. Страница `404.html`, canonical, Open Graph, robots.txt и sitemap.xml настроены на этот путь. При переносе в другой репозиторий обновите эти адреса.

## Демонстрационные функции

Поиск, фильтры, подборка, тема и концептуальный конструктор подарка предназначены для просмотра в браузере. Данные форм не отправляются и не сохраняются. Локальные настройки могут оставаться в хранилище браузера, пока посетитель их не очистит. Страница конфиденциальности описывает эти ключи и инфраструктуру GitHub Pages.
